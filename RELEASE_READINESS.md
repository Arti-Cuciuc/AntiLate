# Проверка перед Android-релизом — 2026-09-14

## Статус

Код прошёл перечисленные ниже автоматические проверки. Это не сертификация
безопасности и не подтверждение работы финального APK. EAS/Gradle и проверки
на физическом устройстве в рамках этой проверки не запускались.

## Версия и сборка

- Пользовательская версия: 1.0.0; Android package: com.antilate.app.
- Исходный versionCode: 2. Во всех EAS-профилях включён autoIncrement.
  Фактический номер следующей сборки определяет EAS; используется local source.
- preview создаёт самостоятельный APK, production по умолчанию предназначен
  для магазина. SDK остаётся Expo 54.0.37, без принудительной миграции.
- Для обновления поверх установленного приложения нужны тот же package и
  ключ подписи. Текущий установленный versionCode не считан с телефона.

## Исправлено

- Проверка реальных календарных дат, времени, длительности и сохранённых планов.
- Восстановление вычисленного времени выхода вместо доверия старому leaveTime.
- Старое уведомление больше не восстанавливается через fallback хука.
- Действие старого уведомления не останавливает другой уже активный сигнал.
- Последовательная синхронизация планировщика в одном JS runtime.
- Смена звукового канала обновляет ожидающие триггеры, сохраняя midpoint
  и не воспроизводя уже подтверждённый сигнал сборов.
- Ошибка сохранения состояния уведомлений больше не выдаётся за успешную запись.
- Ошибка загрузки шрифтов не оставляет стартовый экран пустым навсегда.
- .env и дополнительные файлы ключей исключены из Git.

## Проверки

- `npm test`: реальные TypeScript-модули; даты/смена дня и года, високосность,
  полночь, midpoint, повторения, повреждённые данные, сериализация, конкурентная
  синхронизация, смена канала, устаревшие действия и ошибки записи.
  Android/Notifee в сервисных тестах заменены контролируемыми mocks.
- `npm run typecheck`: TypeScript.
- `git diff --check`: формат diff.
- `npx expo install --check`: совместимость по локальной таблице SDK;
  онлайн-таблица в этом запуске недоступна.
- `npx expo config --type public --json`: чтение конфигурации без сборки.
- Поиск в src/modules/plugins не выявил fetch/axios/eval/WebView и вывода
  пользовательских данных в console. Это ограниченная статическая проверка.

## Зависимости: остаётся работа

`npm audit` до исправлений: 32 затронутых пакета (14 high, 18 moderate).
После `npm audit fix --ignore-scripts`, без --force: 26 (9 high, 17 moderate),
critical — 0. Числа включают зависимые пакеты, а не только независимые дефекты.

Остались цепочки image-size/Metro, postcss, uuid/xcode и
decode-uri-component/query-string/React Navigation. Значительная часть касается
инструментов сборки; это не повод считать все предупреждения безвредными.
Не обрабатывать непроверенные изображения/CSS при сборке и не публиковать Metro
в открытый интернет. Исправления через новую основную версию Expo требуют
отдельной миграции и новой проверки нативных уведомлений.

## Не закрытые проверки перед выпуском

1. Проверить APK без Metro и без компьютера, затем обновление поверх предыдущей
   версии с сохранением встреч, групп, шаблонов и темы.
2. Заблокированный экран, выгрузка из списка приложений, энергосбережение,
   перезагрузка; отказ/отзыв каждого разрешения. Force stop — отдельное
   системное ограничение, не эквивалент обычной выгрузке приложения.
3. ОК, midpoint, «Я вышел», одновременные встречи, удаление/редактирование,
   повторяющиеся встречи несколько дней без открытия приложения.
4. Звук по умолчанию выключен; проверить включённый звук, DND и громкость.
5. Смена часового пояса/системного времени, ночной переход даты и DST.
6. Исправлено 2026-10-07: ошибки чтения встреч/групп/шаблонов блокируют
   гидрацию и запись до успешной повторной загрузки. Ошибки сохранения видны
   пользователю; актуальные изменения можно записать повторно. Записи идут
   последовательно. До успешной записи изменения остаются только в памяти.
   Автоматические тесты проверяют отказ чтения/записи, повреждённые данные,
   повторные попытки и порядок быстрых правок. Это не резервная копия при
   удалении приложения или очистке его данных.
7. Проверить восстановление системных триггеров после отзыва разрешения
   точных будильников: совпадение локального fingerprint ещё не доказывает,
   что триггер остался в Android. Межпроцессные гонки не покрыты JS-очередью.
8. Privacy: AsyncStorage не шифруется; напоминания показывают место на экране
   блокировки (PUBLIC), launcher activity имеет showWhenLocked. До публичного
   выпуска решить, допустим ли доступ к остальному UI поверх блокировки.
9. Иконка приложения, adaptive/monochrome варианты, splash и финальные сведения
   о приложении. Финальная сборка и короткий ручной smoke test обязательны.

Итог: исправления и тесты готовы; статус «полностью безопасно и готово к
публичному запуску» пока не присваивается.
