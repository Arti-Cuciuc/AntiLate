# AntiLate website

Самостоятельный статический сайт на React, TypeScript, Vite и Tailwind CSS 4.
Зависимости и lock-файл отдельные от Expo-приложения. Основной сайт на русском.
Manrope и иконка хранятся локально: внешние CDN для оформления не нужны.
Превью главного экрана — DOM-адаптация мобильных компонентов, а не отдельный
дизайн: палитры, шкала текста и параметры навбара импортируются непосредственно
из `src/constants` приложения, контраст групп — из `src/utils/groups.ts`.
Экран 390 × 844 масштабируется целиком без изменения пропорций элементов.
В блоке возможностей показаны отдельные демонстрационные экраны групп,
повторяющихся шаблонов и темы; изменения данных внутри них отключены.
Тема переключается нажатием на варианты внутри телефона, включая режим
«Как в системе», который реагирует на системное оформление браузера.

## Разработка

Из папки `website`, Node.js 22.18+ (или актуальная поддерживаемая версия):

```bash
npm ci
npm run dev
```

## Проверки и сборка

```bash
npm test
npm run build
npm run preview
```

## APK

Если в корне репозитория есть `AntiLate.apk`, Vite отдаёт его по адресу
`/downloads/AntiLate.apk` во время разработки и копирует в `dist/downloads`
при сборке. Кнопки скачивают этот файл напрямую, без запросов к GitHub.
APK остаётся исключённым из Git: текущий файл больше 100 МБ. Для публикации
можно загрузить готовый `dist` на статический хостинг или разместить APK в
GitHub Releases. В сборке на сервере из Git этого локального файла не будет.

Без локального файла кнопки находят `.apk` в последнем опубликованном GitHub Release
репозитория `Arti-Cuciuc/AntiLate`. Загрузите подписанный самостоятельный APK
в публичный, не prerelease-релиз. Файл автоматически станет доступен на сайте.
Если релиза нет, API недоступен или APK отсутствует, показывается сообщение
и ссылка на список версий. API вызывается только при нажатии кнопки скачивания.

Для фиксированного APK скопируйте `.env.example` в `.env.local` и заполните
`VITE_APK_URL` прямой HTTPS-ссылкой на файл (имеет приоритет над локальным APK). Значения `VITE_*` публичны:
никогда не добавляйте сюда токены. При изменении настройки пересоберите сайт.

## Публикация

На Vercel или Netlify используйте весь репозиторий, выберите корень проекта
`website`, команду `npm run build` и выходную папку `dist`. На Vercel включите
«Include source files outside of the Root Directory in the Build Step»,
так как превью импортирует общие параметры приложения из родительского `src`.
Backend не требуется. Для другого статического хостинга
загрузите содержимое `dist` в корень домена. При размещении в подпапке отдельно
настройте Vite base и пути ресурсов.

Перед публикацией: загрузите APK, проверьте реальную загрузку на телефоне,
установку и обновление поверх старой версии. Иллюстрации интерфейса на сайте
являются интерактивными примерами, а не живыми пользовательскими данными.

## Файлы

- `src/sections` — секции страницы.
- `src/components` — шапка, иллюстрация приложения, кнопки скачивания.
- `src/lib/release.ts` — конфигурация репозитория, проверка ссылок и поиск APK.
- `src/styles.css` — токены бренда, Tailwind и стили иллюстраций.
- `tests` — проверки выбора APK и безопасности ссылок.
- `public` — локальные шрифты и иконки.

Исходные файлы Manrope распространяются на условиях OFL;
лицензия находится в `public/fonts/OFL.txt`.
