# AntiLate

Android-приложение, которое помогает вовремя начать собираться и выйти на встречу.
Время выхода рассчитывается из времени встречи и продолжительности дороги,
а время начала сборов — с учётом указанной пользователем длительности подготовки.

## Возможности

- Создание, редактирование и удаление встреч.
- Живой отсчёт до сборов и выхода; сортировка по времени выхода.
- Пользовательские группы с названиями и цветами.
- Шаблоны встреч и повторения по дням недели с фильтром «Расписание».
- Локальные Android-напоминания, экран сигнала, вибрация и действия уведомления.
- Светлая, тёмная и системная темы.
- Локальное хранение встреч, групп, шаблонов и настроек.

Интеграции с картами и календарём в текущую версию не входят.

## Технологии

Expo SDK 54, React Native 0.81, React 19, TypeScript, NativeWind 4,
Reanimated 4, AsyncStorage, Notifee и локальный Android Expo-модуль.

## Установка и запуск

Нужны Node.js 20.19+ совместимой поддерживаемой версии и npm.
После клонирования репозитория выполните в его корне:

```bash
npm ci
npm start
```

Expo Go подходит для проверки интерфейса, но не поддерживает нативные alarm-функции.
Для проверки уведомлений установите development APK и запустите:

```bash
npm run start:dev-client
```

Создание development APK требует доступа к проекту Expo и его ключам подписи:

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile development
```

При работе с собственной копией проекта настройте свой EAS-проект вместо
использования идентификатора исходного проекта в `app.json`.

## Проверки

```bash
npm run typecheck
npm test
git diff --check
```

Тесты проверяют расчёты, повторения, локальное хранение и логику уведомлений.
Нативные Android-сервисы в автоматических тестах заменены mocks;
работу на заблокированном экране и с ограничениями батареи нужно проверять
на физическом устройстве.

## Самостоятельный APK

```bash
npx eas-cli@latest build --platform android --profile preview
```

Профиль `preview` создаёт устанавливаемый APK, которому не нужен Metro.
Профиль `production` предназначен для сборки Android App Bundle для магазина.
Для обновления приложения без удаления данных сохраняйте package
`com.antilate.app` и тот же ключ подписи.

APK не хранится в Git. Готовые версии можно размещать в **GitHub Releases**
и давать ссылку на файл релиза с сайта приложения.

## Уведомления и данные

На телефоне откройте «Настройки → Уведомления», проверьте необходимые доступы
и выполните тестовый сигнал. Полноэкранное отображение и работа в фоне зависят
от разрешений Android и ограничений производителя устройства.
Принудительная остановка приложения через системные настройки может блокировать
напоминания до следующего запуска.

Данные хранятся локально через AsyncStorage, без шифрования и облачной резервной
копии. Удаление приложения или очистка его данных может удалить все встречи.
Информация о встрече может отображаться на экране блокировки.

## Структура

```text
App.tsx                   Шрифты и корневые провайдеры
src/AntiLateApp.tsx        Координация экранов и состояния
src/screens/              Экраны приложения
src/components/           Переиспользуемые UI-компоненты и анимации
src/hooks/                Состояние и жизненный цикл
src/storage/              Локальное хранение и обработка ошибок
src/notifications/        Планирование и действия уведомлений
src/utils/                Расчёты и валидация
src/constants/            Тема, типографика и общие параметры
src/types/                Типы данных
modules/antilate-alarm/    Исходники нативного Android-модуля
plugins/                  Настройка Android через Expo config plugin
assets/                   Ресурсы приложения
design/icon/              Исходник иконки, превью и история дизайна
scripts/                  Вспомогательные инструменты
tests/                    Автоматические тесты
```

Корневые `android/` и `ios/` генерируются Expo и не публикуются в Git.
Папка `modules/antilate-alarm/android/` содержит исходники и должна оставаться
в репозитории.

Готовые PNG иконки уже включены в проект. Необязательный генератор и требования
к его запуску описаны в [design/icon/README.md](design/icon/README.md).
